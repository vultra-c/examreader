# samples — 测试文件

## 测试知识点.json

用于测试手环端「知识点 JSON 阅读器」的示例文件。

### 使用方法

**方式一：BandBurg 脚本（电脑 → 手环）**
1. 运行 `bandburg-kdreader.js`
2. 在「选择TXT/JSON考点文件」选择本文件
3. 选完自动开始传输（简化流程，无需再点导入按钮）

**方式二：安卓端《闪念小抄》App（手机 → 手环）**
1. 打开手机端 App，连接手环
2. 选择本 JSON 文件推送

### 传输后验证

手环主页会出现「测试知识点」文件（副标题：知识点 JSON）：
- 2 个科目：物理（3 条）、化学（2 条）
- 每条包含 title / desc / points / raw / formulas 全部字段
- 打开详情可验证：原文分页、要点列表、公式文本显示

### JSON 结构要求

```json
{
  "科目名": [
    {
      "id": 1,
      "title": "必填·条目标题",
      "desc": "可选·简介",
      "points": ["可选·要点数组"],
      "raw": "可选·整段原文（自动分页）",
      "formulas": ["可选·公式数组"]
    }
  ]
}
```

- `title` 唯一必填，缺失该条目被丢弃
- 顶层必须是对象 `{}`，不能是数组 `[]`
- 文件编码 UTF-8（无 BOM）
