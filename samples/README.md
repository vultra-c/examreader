# samples — 测试文件

## 测试JSON完整示例.json（推荐）
**更完整的知识点 JSON，覆盖 语文/英语/生物 6 个条目（含长原文+公式）。**
用于验证：进度记忆（科目+条目）、公式文本、原文分页、条目列表、字号调节。

## 测试知识点.json
精简版 JSON，用于快速验证 JSON 阅读器各字段（2 科目 × 5 条目）。

### 使用方法
**方式一：BandBurg 脚本（电脑 → 手环）**
1. 运行 `bandburg-kdreader.js`
2. ① 选择手环目标文件夹（默认主页）
3. ② 点「导入单个 TXT / JSON 文件」→ 选本文件 → **选完自动传输**，无需再点导入按钮
4. 批量：用「多选/整目录/队列」选好后**填手环新文件夹名即自动传入**

**方式二：安卓端《闪念小抄》App（手机 → 手环）**
1. 打开手机端 App，连接手环
2. 选择本 JSON 文件推送

### 传输后验证（以 测试JSON完整示例.json 为例）
手环主页会出现「测试JSON完整示例」文件（副标题：知识点 JSON）：
- 3 个科目：语文（2 条）、英语（2 条）、生物（2 条）
- 同一条目含**：要点 / 长原文（自动分页）/ 公式文本**
- 打开详情后返回，重新进入会**恢复到上次阅读的科目与条目**（新增进度记忆）
- 阅读设置页 → 「回到上次位置」可一键跳回上次条目

### JSON 结构要求
```json
{
  "科目名": [
    {
      "id": 1,
      "title": "必填·条目标题",
      "desc": "可选·简介",
      "points": ["可选·要点数组"],
      "raw": "可选·整段原文（自动分页）",
      "formulas": ["可选·公式数组"]
    }
  ]
}
```
- `title` 唯一必填，缺失该条目被丢弃
- 顶层必须是对象 `{}`，不能是数组 `[]`
- 文件编码 UTF-8（无 BOM）
- 公式图命名：`{科目}_{id}.png`，需放入手环 `internal://files/formulas/`
