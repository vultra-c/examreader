## 技能核心规则

### 规则 1: 连接顺序不可省略

连接必须严格按 5 步顺序执行。跳过任何一步都会导致注册失败：

```
1. removeListener(oldNode)    → 清理旧监听器，先置空 currentNode
2. getConnectedNodes()        → 发现设备，拿到 Node.id
3. checkPermissions()         → 检查 DEVICE_MANAGER + NOTIFY 权限
4. launchWearApp(nodeId, path) → 启动手环快应用
5. messageApi.addListener()   → 注册消息监听
```

### 规则 2: "已注册"不是错误

`addListener` 返回 "You have registered" 时，监听器仍在工作，必须视为连接成功。这是 App 重新打开时的正常现象。

### 规则 3: 线程安全

`onMessageReceived` 在 SDK 后台线程回调。消息处理器表必须用 `ConcurrentHashMap`。所有 UI 更新通过 `Handler.post()` 切回主线程。

### 规则 4: 消息用 tag 路由

每条消息是 JSON 字符串，顶层含 `tag` 字段：
- `tag="file"` → TxtTransferHandler 处理
- `tag="tree"` → TreeSyncHandler 处理

### 规则 5: 分片传输是请求-确认模式

每发一个数据分片（8000 字符），必须等手环回复 `next_chunk` 才能发下一片。每步有 15 秒超时。

### 规则 6: data 字段是二次编码的 JSON 字符串

`data` 字段的值不是 JSON 对象，而是 JSON 字符串（需要 `JSON.parse` 二次解码）。这是协议的设计约定。

### 规则 7: Vela 端用 interconnModule 模式

每个功能模块继承 `interconnModule`，设置静态 `name` 属性作为 tag，通过 `register()` 方法自动绑定发送和监听。

## Android 端实现模板

### WearableManager（连接管理）

核心方法签名：
- `connect()` — 执行 5 步连接流程
- `addListener(tag, callback)` — 注册 tag 消息处理器
- `sendRawMessageWithCallback(message, callback)` — 发送消息
- `destroy()` — 先置空 currentNode，再异步 removeListener
- `isConnected()` — 返回 `connected && currentNode != null`

关键实现要点：
- `messageHandlers` 用 `ConcurrentHashMap<String, MessageCallback>`
- `currentNode` 用 `volatile` 修饰
- `connect()` 开头先 `removeListener(oldNode)` 再 `getConnectedNodes()`
- `registerMessageListener` 的 `onFailure` 中检查 "You have registered"
- 所有 UI 回调通过 `handler.post()` 发到主线程

### TxtTransferHandler（文件传输）

消息协议（手机→手环，`stat` 字段路由）：
- `startTransfer` — 开始传输，携带 filename/total/wordCount/folder
- `d` — 数据分片，data 字段是 JSON 字符串
- `chapter_complete` — 章节分片发完
- `transfer_complete` — 全部完成
- `cancel` — 取消

消息协议（手环→手机，`type` 字段路由）：
- `ready` — 手环就绪
- `next_chunk` — 请求下一片
- `chapter_chunk_complete` — 最后一片接收完
- `chapter_saved` — 章节已保存到 storage
- `transfer_finished` — 全部完成
- `error` — 错误
- `cancel` — 取消

### TreeSyncHandler（文件树同步）

消息协议（手机→手环，`action` 字段路由）：
- `getTree` — 请求文件树
- `createFolder` — 创建文件夹（name, parentId）
- `deleteNode` — 删除节点（nodeId）

消息协议（手环→手机，`response` 字段路由）：
- `treeData` — 返回 JSONArray 树结构
- `folderCreated` — 创建结果（folderId, success）
- `nodeDeleted` — 删除结果（success）

### UI 架构

- 主题: `Theme.Material.Light.NoActionBar`
- 布局: ScrollView → 纵向 LinearLayout，卡片式
- 连接状态栏: 三个 drawable 切换（绿/橙/红）
- 文件树: 动态 LinearLayout + 缩进，不用 RecyclerView
- 按钮: selector drawable 实现 pressed/disabled 态

## Vela 手环端实现模板

### interconn.js（通信封装器）

```javascript
import interconnect from "@system.interconnect";

export default class interconn {
    constructor() {
        this.conn = interconnect.instance();
        this.conn.onmessage = ({data}) => {
            const { tag, ...payload } = JSON.parse(data);
            this.connected = true;
            if (this.callbacks[tag]) {
                this.callbacks[tag](payload);
            }
        }
        // onclose, onerror, onopen...
    }
    register(module) {
        return new module({
            send: (payload) => this.send(module.name, payload),
            addListener: (callback) => this.addListener(module.name, callback),
            // ...
        });
    }
}
```

### interconnfile.js（文件接收模块）

- 继承 `interconnModule`，`static name = 'file'`
- `startTransfer` → 回复 `ready`
- `saveChapter` → 追加内容，回复 `next_chunk` 或 `chapter_chunk_complete`
- `completeChapterTransfer` → 调用 `dataManager.saveBluetoothContent` 保存，回复 `chapter_saved`
- `handleTransferComplete` → 回复 `transfer_finished`

### interconnTree.js（文件树同步模块）

- 继承 `interconnModule`，`static name = 'tree'`
- `handleGetTree` → 调用 `dataManager.getFolderTreeForBluetooth()` 返回树
- `handleCreateFolder` → 调用 `dataManager.createBluetoothFolder()` 创建
- `handleDeleteNode` → 调用 `dataManager.deleteBluetoothNode()` 删除

### dataManager.js（数据管理）

存储键: `KD_BT_CONTENT`
数据结构: JSON 数组，每项含 `{id, name, type, content?, folder?, parentId?}`
ID 规则: `bt_xxx` 为文件，`bt_folder_xxx` 为文件夹
内存缓存: `_btContentCache` 避免重复读 storage

分页参数: 336x480 屏幕，每行 11 字，每页 15 行

### manifest.json 关键配置

```json
{
    "features": [
        {"name": "system.interconnect"},
        {"name": "system.storage"},
        {"name": "system.file"}
    ],
    "config": {"designWidth": 336}
}
```

## 常见错误速查

| 症状 | 原因 | 解决方案 |
|------|------|---------|
| 注册失败 | 未调用 launchWearApp | 在 addListener 前调用 launchWearApp |
| 注册失败 | 未处理"已注册"错误 | onFailure 中检查 "You have registered" |
| 重复注册 | 重连未清理旧 listener | connect() 开头先 removeListener |
| ConcurrentModificationException | HashMap 非线程安全 | 改用 ConcurrentHashMap |
| 传输卡死 | 超时未处理 | 每步加 15 秒超时 + cancel 消息 |
| 手环收不到消息 | 快应用未启动 | launchWearApp(nodeId, "/pages/index") |
| 闪退 | UI 线程被阻塞 | 所有 UI 操作通过 Handler.post |
| data 字段解析失败 | 当作 JSON 对象 | data 是 JSON 字符串，需二次 parse |
